# CodeAtlas

带本地 AI 的项目阅读工具 —— 帮不用读代码的人,看懂自己电脑里的项目和文档。

现在越来越多项目是和 AI 一起写出来的:文件越来越多,结构越来越绕,过段时间连项目主人自己都说不清哪块是哪块。CodeAtlas 把项目摊开给你看,再配一个在本机运行的 AI 在旁边答疑:哪个文件是干什么的、功能藏在哪里、这篇外文文档讲了什么、网上最新的说法和你项目里的现状对不对得上,都能就地问、就地查。

> **项目状态:正在快速开发中,暂不提供稳定版安装包。** 想试用请按下面「从源码运行」一节,用开发模式启动。功能和界面仍在频繁变化,本文档描述的是当前开发分支的实际能力;尚未完成的功能单独列在「正在开发」一节,不会混进正式功能里介绍。

## 核心优势:AI 在本地,项目不用出门

- **内置推理引擎,模型在本机运行。** 设置里有「模型货架」:按你的机器配置挑一个带得动的模型,下载完自动配好就能聊,不需要先懂一堆部署概念。也可以改接 LM Studio,或自备兼容的在线 API。
- **为本地模型设计的工作方式。** 翻文件、搜内容、整理证据、核对出处这些重活由程序完成,模型只负责理解和表达;回答引用了哪些文件、联网时实际搜过和打开过哪些页面,界面上都有账可查,而不是让模型凭记忆随口说。
- **浏览不惊动 AI。** 单纯打开、阅读文件不会触发任何模型调用;只有你主动提问、翻译或开启联网查证时才会用到模型。

## 现在就能用

### 读项目,也读文档

- 打开电脑上的任意文件夹作为工作区,左侧文件树按真实目录摊开,悬停任意文件就能看到一句大白话用途说明
- Markdown 以排版后的阅读形态打开,带大纲导航;代码文件按语法着色;`.docx` 文档转成干净排版阅读;图片(JPG / PNG)可缩放查看,音频(MP3 / WAV)可直接播放
- 多页签与分屏:几个文件并排对照着看;可以给文件或文件夹右键写一句自己的备注,下次悬停优先显示你的备注
- 全文搜索与文件搜索:找一个词、一项功能到底落在哪些文件里

### 和本地 AI 聊你的项目

- 把文件或图片拖进对话就能问:「这个文件是干嘛的」「登录功能在哪几个文件里」「改这里会影响什么」
- AI 可以在你的授权范围内自己翻文件、搜内容来找答案,回答带具体文件依据;它只有读取和检索能力,不能改动你的任何文件
- 没打开项目时也能打开自由对话,当作一个纯本地的聊天窗口使用

### 用本地模型翻译文档

- 对 Markdown 和纯文本文档(`.md` / `.txt` / `.rst` / `.adoc` 等)右键选择「翻译成……」,支持简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语共 8 种目标语言
- 译文以对照页签打开:原文和译文按段对应,悬停任意一段,两侧同步高亮;滚动时另一侧自动跟到同一段,长文档不用两边来回找
- 译文只在内存中保留、不写入磁盘,关掉译文页签即结束

### 让本地模型看着你的项目,去查网上的信息

- 联网查证默认关闭,你手动开启后,模型可以联网搜索、打开网页正文核对细节,还可以打开公开的 GitHub 仓库直接读源码
- 查到的资料会和你项目里的文件放在一起回答:比如「这个库的新版本改了什么,我的项目受不受影响」,它会先看你的项目现状,再去查最新资料,而不是只给你一段通用介绍
- 本轮实际搜过、打开过的链接都会列在回答旁,搜没搜、查了哪里,一眼可查

### 关系图谱:看结构,不看代码

- 以图的形式呈现项目里文件与模块之间的引用关系:谁引用谁、哪些文件被引用得最多、每个模块大致负责什么
- 适合在接手一个陌生项目,或回看一个 AI 帮你写完的项目时,先花几分钟摸清整体形状,再决定细看哪里

## 典型用法

1. **接回一个搁置的项目:** 打开文件夹,先看图谱摸结构,再把拿不准的文件拖进对话问清楚,很快就能想起这个项目是怎么回事。
2. **读一篇外文文档:** 打开任何一篇 Markdown 文档,右键翻译成中文,原文译文对照着读,看不懂的段落直接问旁边的 AI。
3. **边写边确认:** 用其他工具 vibe coding 的同时,把项目在 CodeAtlas 里开着:新生成的文件是干什么的、和已有结构合不合、要用的库网上最新文档怎么说,随时查证,不用离开当前项目去别处拼信息。

## 隐私与安全

- 文件扫描、阅读和本地模型的推理都在你自己的电脑上完成,项目内容不需要上传
- 联网查证默认关闭;只有开启后,模型才会访问搜索引擎与网页
- 如果你选择连接在线 AI 服务,发送到该服务的代码片段以你填写的服务地址为准,请只连接可信服务
- AI 配置保存在你电脑的用户目录中,不进入任何代码仓库;对话中的 AI 只有读取与检索权限,不能修改或删除文件

## 从源码运行

目前仅面向 Windows 10 / 11(x64)。

```bash
git clone https://github.com/feix95/code-atlas.git
cd code-atlas
npm install
npm run dev
```

启动后选择一个项目文件夹即可开始浏览,基础阅读不需要配置 AI。想用本地 AI 时,打开底栏的「设置 AI」:

- **模型货架(推荐):** 按机器配置挑选模型,下载完成后自动配置,下载的模型只保存在你本机的用户目录里
- **LM Studio:** 先在 LM Studio 中启动本地服务,再把服务地址和模型名填入设置
- **在线 API:** 在设置中填写服务地址与密钥,并确认隐私提示后使用

## 给开发者

```bash
npm run dev        # 开发模式启动(带热更新)
npm test           # 全部自测(纯函数级,不访问真实网络)
npm run typecheck  # 类型检查
npm run lint       # 代码检查
npm run build      # 构建
npm run test:journey # 真机旅程验收(需先 build)
```

技术栈:Electron + React + TypeScript;语法分析使用 tree-sitter(WebAssembly),本地推理引擎为 llama.cpp。完整开发历程见 [CHANGELOG.md](./CHANGELOG.md)。
