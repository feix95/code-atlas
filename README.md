# CodeAtlas

AI 代码地图 —— 帮你不用读代码,也能看懂整个项目。

## 开发

```bash
npm install
npm run dev # 启动应用(开发模式,带热更新)
```

## 常用命令

```bash
npm run lint # 代码检查
npm run typecheck # 类型检查
npm run format # 格式化
npm run test:scanner # 目录扫描器自测
npm run test:parser # 语言识别器自测
npm run test # 全部自测
npm run build # 构建产物
```

## 当前支持的核心功能

- 把任意文件夹画成一张可浏览的「代码地图」:目录树 + 每个目录/文件一句大白话速览,整个 C 盘也能秒开(分级扫描,点哪探哪)
- 选中任何文件/文件夹,AI 用大白话讲它是干嘛的:代码看结构、二进制认文件头魔数、系统目录用常识,证据不够就老实说,绝不编造
- 「自由对话」找 Atlas 小探针随便聊:当前选中资料只当参考挂件、可选举证联网查证(默认关,查没查界面挂实账)、多轮上下文不失忆
- Git 修改翻译:谁动了代码、动了多少行,AI 对着 diff 讲人话,改哪里会牵连谁
- 项目关系分析:谁引用谁、影响范围最大的文件排行,重构先看它
- 外观自己说了算:亮暗三档(跟随系统/白天/黑夜)、三套配色预设、主题色辅助色自定、界面缩放自适配各种屏幕
- 隐私优先:全部本地运行,模型跑在自己电脑,默认完全离线
