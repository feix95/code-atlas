# CodeAtlas

AI 代码地图 —— 帮你不用读代码,也能看懂整个项目。

把任意文件夹画成一张能逛的「地图」:目录树挂着大白话速览,AI 小探针坐在旁边,指着哪个文件就给你讲哪个,证据不够就老实说「我不知道」,绝不编造。

## 下载安装(普通用户看这里)

1. 到 [Releases 页面](https://github.com/feix95/code-atlas/releases) 下载最新的 `CodeAtlas-Setup-x.x.x.exe`
2. 双击安装,跟着向导走:可以自己挑安装位置(免管理员权限)
3. 打开 CodeAtlas,选一个文件夹(整个 C 盘也行,分级扫描不会卡)——地图就出来了

> 目前仅支持 Windows 10/11(x64)。

### 卸载与彻底清理

- **正常卸载**:Windows「设置 → 应用 → 已安装的应用」里找到 CodeAtlas 点卸载(或开始菜单里的卸载快捷方式),程序本体删干净
- **你的数据会保留**:AI 配置、窗口位置、从模型货架下载的模型等存放在 `C:\Users\<用户名>\AppData\Roaming\CodeAtlas\`,卸载不会动它们,重装后原样还在
- **想彻底清干净**:卸载后手动删除上面那个文件夹即可(下载过模型的话,模型占大头)

## AI 功能怎么开

Atlas 小探针的 AI 跑在**你自己电脑上的本地模型**里,不上传代码、默认完全离线。开工前需要准备一个本地模型,二选一:

- **LM Studio**(推荐新手):装好 LM Studio 并启动本地服务,在 CodeAtlas 的设置里填上服务地址和模型名
- **模型货架**(零门槛):AI 引擎已经随安装包自带,打开设置里的「模型货架」,按大小挑一个你机器带得动的模型点「下载并使用」,下完自动配好直接能聊

配好就能聊:选中文件/文件夹问「这是干嘛的」,翻文件找东西,翻译 Git 改动,随口提问都行。

## 它能干什么

- **全盘秒开**:分级扫描 + 节点预算,点 C 盘也不卡,每个目录/文件后面挂一句大白话
- **文件预览**:全文预览 + 虚拟滚动,代码按 VS Code 官方配色分色,亮暗两套主题自动跟
- **AI 讲解**:代码看结构、二进制认文件头魔数、系统目录用常识;只读沙盒,小探针没有任何写文件的权限
- **自由对话**:多轮上下文、可选举证联网查证(默认关,查没查界面挂实账)
- **Git 翻译**:谁动了代码、动了多少行,AI 对着 diff 讲人话
- **项目关系分析**:谁引用谁、影响范围最大的文件排行(当前支持 JS/TS 族)
- **外观自己说了算**:亮暗三档、三套配色预设、主题色自定、界面缩放自适配

## 隐私与安全

- 全部本地运行,模型跑在自己电脑,默认完全离线
- **只读沙盒**:Atlas 没有改文件的能力,指它到整块硬盘也动不了你一根手指头的东西
- AI 配置存在你自己电脑的用户目录,不进任何仓库

## 给开发者

```bash
npm install        # 装依赖
npm run dev        # 启动应用(开发模式,带热更新)
npm test           # 全部自测(20+ 套件,纯函数级)
npm run typecheck  # 类型检查
npm run lint       # 代码检查
npm run dist       # 打 Windows 安装包(产出在 dist/)
```

技术栈:Electron + React + TypeScript,语法分析用 tree-sitter(wasm),零重型后端依赖。完整开发历程见 [CHANGELOG.md](./CHANGELOG.md)。
