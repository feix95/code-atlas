# 文件预览编辑（Obsidian 式）需求方案

> 状态: 需求已定稿;未开工。

## 1. 定位

产品定位调整: CodeAtlas 由「不读代码的项目主人的代码地图」转向「协助小白 vibe coder 的多功能便利协助工具」。本模块为此定位下的首个功能: 文件预览从「只读文本窗」进化为 Obsidian 式可直接编辑。交接文档「产品与验收契约」中的核心用户定义需在本模块落地时同步修订。

## 2. 目标效果

对标 Obsidian:

- md 文件打开即 Live Preview(实时预览): 正文保持排版渲染,仅光标所在行显露原始标记,可直接编辑。
- 三档模式: Live Preview(默认)/ 阅读 / 源码,经页头开关与页签右键菜单切换。
- 代码及其他文本文件: 源码态直接可编辑。
- 全程自动保存,无「保存」概念负担。

## 3. 已定决策

| 决策点       | 结论                                                                                                                                     |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| md 默认姿态  | 打开即 Live Preview 可编辑;阅读、源码为可切换档位                                                                                        |
| 编辑器引擎   | 引入 CodeMirror 6(Obsidian 同源引擎);Live Preview 与阅读模式由同一引擎渲染,MiniMD 退回仅服务对话气泡                                     |
| 保存策略     | 全自动保存: 停笔约 1 秒防抖落盘;切换页签/切换模式/关闭窗口前强制落盘;不设脏标记                                                          |
| 外部改动     | 仅监视打开着的页签(每签一条 fs.watch);无未落盘编辑时外部改动→内容静默刷新;撞上编辑间隙→用户版本覆盖写盘并弹人话提示;全项目监视记入待办池 |
| 可编辑范围   | 所有文本文件;沿用预览准入三道闸(二进制/超大/读取失败),闸外文件保持只读                                                                   |
| 文件树增删改 | 不做,另立模块                                                                                                                            |
| 格式工具栏   | 不做,与 Obsidian 桌面版一致,md 语法手写                                                                                                  |
| 保存后联动   | 保存成功后自动对该文件重跑 analyzeFile,刷新依赖图与摘要                                                                                  |
| 选区引用共处 | 编辑态用编辑器原生选区,「引用到对话」走右键菜单;角标美术不随新引擎迁移,整套退役(引用功能不受影响)                                        |

## 4. 三档模式规格(md 系文件)

| 档位         | 渲染方               | 可编辑 | 说明                                                          |
| ------------ | -------------------- | ------ | ------------------------------------------------------------- |
| Live Preview | CodeMirror 6         | 是     | 默认档;排版渲染与编辑同屏,光标行显露源码                      |
| 阅读         | CodeMirror 6(只读态) | 否     | 内联标题、fileLinks 文件链接沿用现口径保持可点;划选为原生高亮 |
| 源码         | CodeMirror 6         | 是     | 行号 + 分色;等价于原代码视图进入编辑态                        |

- 非 md 文件: 仅源码档,可编辑;模式开关保持置灰口径。
- `PaneViewMode` 扩展为 `'live' | 'reading' | 'source'`,账仍记在页签上。
- 模式切换沿用页头 `modeBtn` 与页签右键菜单,扩为三档。

## 5. 编辑与保存规则

- **自动保存**: 输入停止约 1 秒防抖写盘;切页签/切模式/切文件/关窗前强制 flush,杜绝丢字窗口。
- **新 IPC `saveFile`**: 收 `(rootPath, relPath, text)`,主进程经 `joinRoot` 解析并越界拦截,写盘口径与 readPreview 一致;返回写后 mtime 供监视去抖。
- **外部改动(仅盯打开页签)**: 主进程对打开的文件挂 fs.watch,随页签关闭释放;自身写盘产生的事件须按 mtime/内容指纹去抖,避免自激。
  - 无未落盘编辑 → 重新读取并替换编辑器内容(保留光标近似位置)。
  - 有未落盘编辑 → 照常覆盖写盘,弹一条人话提示「这个文件刚被外部改过,已用你编辑的版本覆盖」。
- **编码与行尾**: 按 UTF-8 读写;识别并保留原行尾序列(CRLF/LF)。
- **撤销**: 编辑器原生 undo/redo,会话级,切文件即清。

## 6. 与现有功能的关系

- **选区引用**: 编辑态划选为编辑器原生选区;「引用到对话」改经右键菜单,以编辑器选区生成 ChatCodeRef(行号经 CM6 位置换算,保证 1 起算口径);直拖挂引用照旧。角标美术(首尾角标+左缘竖线)为旧只读 DOM 定制,不随新引擎迁移,全档退役。
- **Ctrl+A**: 编辑态归编辑器原生全选;阅读档维持复制全文。
- **分色**: 源码档分色沿用主进程 tree-sitter 段落账,经 CM6 decoration 上屏,tok-\* 色号不变;Live Preview 的 md 语法分色用 CM6 自身高亮。
- **折行/字号缩放/跳行/Ctrl+滚轮**: 各档与编辑器适配,口径沿用现状(折行偏好、docZoom、聊天跳行在源码档生效)。
- **准入闸**: 二进制/超大/读取失败文件不进入编辑,维持只读展示与现有人话说明。

## 7. 实施前置

- 引入 CodeMirror 6 依赖前必须过 `project-standards`「引入新依赖」闸口并出对照表。
- realm 铁律沿用: 编辑器挂载、事件监听一律走 `ownerDocument`,不摸全局 window(页签撕窗子窗)。
- 编辑集成组件自立即拆(预览交互 + CM6 集成体量),遵守 src/ 单文件 1000 行上限。
- 新增自测脚本登记进 package.json `test` 链。

## 8. 验收标准(草案)

1. md 页签打开即 Live Preview,可边改边看渲染;三档切换内容无损、滚动位置近似保留。
2. 任意文本文件可编辑,停笔约 1 秒自动落盘;外部程序能读到新内容。
3. 外部改动未编辑的打开文件→内容自动刷新;编辑中撞车→用户版本写盘并出现提示。
4. 二进制/超大文件仍只读并显示原有人话说明。
5. 编辑态右键「引用到对话」生成的引用行号与实际相符。
6. 保存后该文件的依赖关系/摘要自动更新。
7. `npm run typecheck` → `lint` → `test` → `build` → `test:journey` 全绿;worktree 验收隔离 userData 等(契约口径)。
