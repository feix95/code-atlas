### 一、文件预览编辑(Obsidian 式)需求表

**功能名称**:文件预览编辑(Obsidian 式)

**目标**:
文件预览从只读文本窗升级为可直接编辑,效果对标 Obsidian: md 文件打开即 Live Preview 边改边看排版,代码文件直接可改,全程自动保存无需手动。服务于产品新定位「协助小白 vibe coder 的多功能便利协助工具」。详细规格见同目录《文件预览编辑-Obsidian式方案.md》。

**核心需求**:

1. **md 三档模式**

   - md / markdown / mdx 文件打开默认进入 **Live Preview**:正文保持排版渲染,光标所在行显露原始标记,可直接打字编辑。
   - 三档可切换: **Live Preview(默认)/ 阅读(只读排版)/ 源码(行号 + 分色原文)**;入口为页头模式开关 + 页签右键菜单。
   - 模式记在页签上,重开保持上次档位。

2. **文本文件编辑**

   - 所有文本文件的源码档均可编辑,行号、分色等现有显示能力保留。
   - 二进制 / 超大 / 读取失败的文件不进入编辑,维持只读展示与原有人话提示。

3. **自动保存**

   - 停笔约 1 秒自动写盘;切换页签、切换模式、切换文件、关闭窗口前强制落盘,不留丢字窗口。
   - 不引入脏标记,用户无「保存」概念负担。
   - 按 UTF-8 读写,识别并保留文件原行尾(CRLF / LF);撤销重做走编辑器原生能力,切文件即清。

4. **外部改动处理(仅监视打开的文件)**

   - 对打开着的文件挂系统文件监视;文件被外部改动时:
     - 没有未落盘编辑 → 内容自动刷新为磁盘新版。
     - 正处在编辑间隙 → 以用户版本覆盖写盘,并弹人话提示「这个文件刚被外部改过,已用你编辑的版本覆盖」。
   - 未打开的文件一律不监视,打开时现读最新内容。
   - 自身写盘引发的监视事件须按修改时间/内容指纹去抖,防止自激。

5. **选区与引用**

   - 编辑态:编辑器原生划选;「引用到对话」经右键菜单,以编辑器选区生成引用,行号口径与现有 ChatCodeRef 一致(1 起算)。
   - 阅读档:右键与直拖挂引用功能全套保留;原角标美术(首尾角标+左缘竖线)为旧只读渲染定制,不迁移到新引擎,整体退役。

6. **保存后联动**

   - 保存成功后自动对该文件重跑单文件分析(analyzeFile),依赖图与摘要标签随之刷新。

7. **渲染与引擎**

   - 引入 CodeMirror 6(Obsidian 同源引擎);Live Preview 与阅读档由同一引擎渲染,保证两档观感一致。
   - MiniMD 退出文件预览,仅保留对话气泡渲染用途。
   - 源码档分色沿用主进程 tree-sitter 段落账,经编辑器装饰上屏,tok-\* 色号不变。

8. **技术约束**

   - 基于现有 Electron + React + TypeScript 栈;IPC 收发严格配对,路径经 joinRoot 解析、越界拦截。
   - 遵守 realm 铁律:编辑器挂载与事件监听一律走 ownerDocument,兼容页签撕窗子窗。
   - CodeMirror 6 为新增依赖,引入前过「引入新依赖」闸口;新增自测脚本登记进 `npm test` 链。
   - 交付前 `npm run typecheck` → `lint` → `test` → `build` → `test:journey` 全绿。

9. **非目标(本模块不做)**

   - 文件树管理操作:新建文件/文件夹、重命名、删除。
   - 全项目文件监视(文件树实时感知)。
   - 格式工具栏、vim 键位、多光标、编辑器内查找替换面板、minimap、diff 对比。
   - md 增强语法:[[wiki 链接]]等(所见即所得表格编辑已纳入范围,对标 Obsidian 1.5 表格编辑器)。
