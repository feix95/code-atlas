# UI 重构 — Obsidian 经典布局(Workspace Layout)需求定稿

> 实施在 worktree 分支进行,不在 main 上直接做。

## 一、目标

把工作台界面重构为 Obsidian 经典式:**图标侧边栏(rail)+ 顶栏(含页签条)+ 文件树面板 + 内容区域**。窗口边框维持现状(只做「隐藏」一档:`frame: false` + 自绘窗控),**本版不换实底**、不动分屏、不做图谱本体。

## 二、目标布局

```
┌──┬───────────────────────────────────────────────────────┐
│收起│ ⌕ │ ← │ → │ ↻ │  页签1  页签2 …      │ ─ │ ▢ │ × │
│  ├──────────┬────────────────────────────────────────────┤
│导│          │                                            │
│览│          │                                            │
│图│ 文件树    │              内容区域                       │
│谱│ 列表      │        (页签 / 功能页面宿主)                 │
│  │          │                                            │
│概│          │                                            │
│览│          │                                            │
│探│──────────│                                            │
│针│ 底部切换区:                                            │
│  │ [项目操作 ⇄ 扫描状态]                                  │
│状│          │                                            │
│设│          │                                            │
└──┴───────────────────────────────────────────────────────┘
```

- 侧边栏为通高窄栏(图标列),「收起」按钮位于栏顶、与顶栏同行对齐;「状态」「设置」两枚沉在栏底。
- **无独立标题栏**:顶栏即最顶行,无标题文字、无品牌 logo;空白区 `app-region: drag` 拖窗。
- **底部 AI 状态栏整条撤除**,状态收进侧边栏状态图标(见第七节)。
- **首页撤除**:启动直进工作区(见第五节「会话恢复」)。

## 三、各区域规格

### 侧边栏(rail,新组件 `IconRail`)

从上到下顺序固定,图标统一走 lucide 风格描边图标(收进 `Icons.tsx` 图标册):

| 图标 | lucide 源 | 行为 |
| --- | --- | --- |
| 收起/展开(栏顶,与顶栏同高对齐) | `panel-right` 水平翻转(= panel-left 形态) | 折叠/展开文件树面板 |
| 项目导览 | 沿用现有 | 打开项目导览(现有 `showProjectGuide` 链路) |
| 关系图谱 | `view`(小葵供稿) | 打开/聚焦「关系图谱」页签(新全局页签,见第五节) |
| 概览 | 沿用现有 | 打开/聚焦当前选中对象的「概览」页签(kind `overview`) |
| 自由对话 | 沿用现有 | 打开/聚焦「Atlas 小探针」页签(kind `chat`) |
| AI 状态(栏底) | 状态点着色图标 | 点击弹浮层(规格见第七节) |
| 设置(栏底) | 沿用现有 | 打开 `SettingsDialog`(弹窗;页签化为追加设计,本版不做) |

无项目打开时:图谱/概览/对话图标禁用置灰;导览、状态、设置可用。

### 顶栏(自绘,兼作窗口拖拽区,即最顶行)

从左往右:

1. **收起钮**:与侧边栏同列对齐(视觉上是 rail 的第一格),点击折叠/展开文件树面板。折叠后面板宽度归零、sash 隐藏、rail 常显;再点恢复上次宽度。折叠状态记进本机偏好。
2. **功能组**(四颗紧密成组):
   - **搜索**:只显示图标(lucide `search`),点击弹出搜索输入框(浮层或顶栏内展开);搜索逻辑沿用现有「搜索已加载的文件」;Esc 收起并还原焦点。
   - **后退 / 前进 / 刷新**:沿用现有 `goNav` / `handleRefresh`,禁用态规则不变。
3. **页签区**(中部):现有页签条上移进顶栏;全部关闭后呈现「页签都关掉了」空态(现有 `TabBody` 逻辑);页签拖放排序、分屏拖放、右键菜单、中键关闭等现有交互原样保留。
4. **窗控组**(右侧紧密三颗,lucide 图标):`minus` 最小化、`square` 最大化/还原、`x` 关闭。现有三圆点退役。

### 文件树面板

- 保留:文件树本体、懒加载、笔记标记、右缘拖宽 sash、可被收起钮折叠。
- 顶部不再放「项目导览」按钮与搜索框(均迁出)。
- **底部「显示切换」区**:一块区域两种内容,切换钮换视图 —
  - 状态视图(默认):现有「扫描完成/部分已扫描 + 文件数 · 文件夹数」。
  - 项目操作视图:「打开项目」按钮 + 路径输入框 + 「前往」(自顶栏迁入,行为不变)。

### 内容区域

- `PaneGroups` 一组/两组页签 + 正文,所有页签与功能页面在此展示;分屏拖放现有行为不动。
- 新增全局页签「关系图谱」:rail 图标打开一张固定页签,单例(重复点聚焦同一张,不再开第二张);本版正文为占位(标题 + 「图谱功能开发中」说明)。
  - 技术要点:现有 `paneKinds` 全是「跟随选中对象」的品类(overview/chat/preview),图谱是**工作区级单例页签**,不进 `KIND_CAPS` 节点过滤;页签模型需扩一个「工作区级页签」位,参与排序/拖拽/钉住/关闭,也进会话恢复。

## 四、会话恢复(顶替首页)

- **首页 `HomePage` 撤除**:启动不再落盘符/最近项目页,直接恢复上次关闭前的工作区;「⌁ CodeAtlas 回首页」钮一并撤除。
- **恢复内容**:上次打开的项目路径、打开的页签(品类 + 目标)、活动页签、当前选中文件/文件夹、文件树折叠态与宽度、分屏比例。
- **自由对话内容不持久化**(沿用「不落盘」契约):页签结构恢复,对话体重新为空。
- **持久化机制**:沿用 `localPrefs` 本地偏好;变更时防抖写入,关窗前兜底写一次。存档损坏就当没存过,走空态。
- **启动行为**:存档的项目路径仍存在 → 自动开图(走现有扫描管线,内容区域显示扫描中);路径已失效 → 落工作区空态页。
- **空态页**(新项目未开时的内容区域):「打开项目」+ 最近项目列表(复用现有 recents 数据,不再单设首页)。

## 五、技术要点与约束

- **壳层抽离(为实底留路)**:窗口外壳样式(圆角 `--radius-window`、悬浮边距、阴影)收拢成独立层,布局代码不依赖外壳;后续换实底只改壳。
- 视觉全部走 `tokens.css` 现有 design tokens;新增间距/尺寸先进 token,不写散值。
- 顶栏 `app-region: drag` 只给空白区;按钮热区 = 视觉范围;搜索浮层、页签右键菜单不吃顶栏裁剪。
- 键盘可达:rail 图标、收起钮、切换开关、搜索框、浮层均支持键盘操作;弹层 Esc 关闭并还原焦点。
- `src/` 单文件 ≤1000 行:`App.tsx` 已近临界,顶栏/rail 接线落独立组件,App 只组装;会话恢复读写单独成模块(建议 `workspaceSession.ts`)。
- 新增可断言逻辑(会话存档读写、折叠偏好、rail 项定义)配自测并登记 `package.json` `test` 链。
- commit 规矩:调试期不 commit,小葵确认后一次性 commit + push;commit 同步 CHANGELOG,不带工具署名。

## 六、本版不做(非目标)

- 设置页页签化(追加设计,后续单独模块)。
- Graph View 图谱本体(只做入口 + 占位页签)。
- 实底窗口/窗框样式切换(后续单独一锤,配方已定:`transparent:false + frame:false + thickFrame 保留 + backgroundColor 同底色`)。
- 分屏拖放、桌宠、气泡、页签拖出变桌宠逻辑不动。
- 副屏失焦蒸发 bug(上游 Electron/Windows 病,实底化或创可贴另议)。

## 七、AI 状态落位(已定:方案 A)

底栏 `ModelStatusBar` 撤除,状态收进 **rail 底部状态图标**:

- **图标形态**:rail 底部一枚图标 + 小圆点着色表状态 —— 未配置灰、热身中转圈(或琥珀)、就绪绿、异常红、外接未连灰;配色从 tokens 领,不自造。
- **点击弹浮层**(锚在图标上方/右侧,Esc/点外收起),内容:
  - 供应商(内置 / LM Studio)+ 状态文案(热身中/就绪/忙/没连上/出岔子,沿用现有口径)
  - 热身进度:**只写字,不画条**(进度条撤除);引擎不报真数就写「热身中……」,沿用 `status.estimated` 的「约」口径
  - 模型名 + 大小(有则显示)
  - 操作:热身中「取消」/就绪「卸下」(仅内置模型生效,沿用 `modelEject`);「AI 设置」(打开设置 AI 节);「日志」(打开 Developer 日志窗)
  - `status.message` 有则显示,超长截断 + 悬停看全文
- **未配置态**:状态点灰 + 浮层里给「设置 AI」引导(沿用现有 `setup.openSettings`)。
- 「AI 讲解尚未设置,项目地图可直接使用」这类安抚文案收进浮层,不再常驻占地方。
- 无障碍:图标按钮带 `aria-label` 与状态朗读(`aria-live` 迁到浮层/图标 title),状态变化不骚扰读屏但可查到。

## 八、验收标准(Definition of Done)

- [ ] rail 图标按序排列(收起/导览/图谱/概览/对话,底部状态+设置),行为正确,无项目时禁用态正确
- [ ] 顶栏顺序:收起 → 搜索/后退/前进/刷新组 → 页签区 → 窗控组;空白区可拖窗;无标题文字与 logo
- [ ] 搜索图标点击弹输入框,搜索行为与现状一致,Esc 收起
- [ ] 文件树折叠/展开可用且跨重启记住;折叠后 sash 隐藏
- [ ] 文件树底部切换区:状态视图 ⇄ 项目操作视图切换正常;打开项目/路径前往完好
- [ ] 关系图谱:rail 图标可打开占位页签,单例;页签可拖、可钉、可关
- [ ] 启动恢复:重开应用还原上次项目/页签/选中/折叠/分屏;对话内容不恢复;路径失效落空态页
- [ ] AI 状态:底栏已撤,rail 状态图标变色正确,浮层信息/操作齐全;热身中取消、就绪卸下可用
- [ ] 首页、底栏、旧标题栏移除后无残留入口/样式死代码
- [ ] 界面四态(加载/空/错/成)完整;全界面键盘可操作
- [ ] 100%/125%/150% 缩放至少两档实测无错位/热区偏移/溢出
- [ ] `npm run typecheck` → `lint` → `test` → `build` → `test:journey` 全绿;CHANGELOG 同步;新自测挂 `test` 链
