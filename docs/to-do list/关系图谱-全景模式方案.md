# 关系图谱 · 全景模式（Panorama）与视图设置浮窗 实施方案

> 状态: 已实施（步骤 1-6 完成，全量验证绿），待小葵验收。在已落地的《关系图谱-实施方案.md》（层级模式）之上扩展，层级模式行为不变。

## 1. 定位

关系图谱新增「全景」模式: 文件夹在当前画布上原地展开 / 收起，展开越多、画布节点越多；引用关系跨越文件夹层级直连，一眼看清文件之间的真实联系。原有「层级」模式（逐层进入）保留，两种模式通过右上角「更多选项」浮窗切换。

## 2. 验收标准

1. 右上角工具区出现「更多选项」按钮（竖排三点，悬停提示「更多选项」），单击弹出视图设置浮窗；点击浮窗外、滚轮、`Esc` 收起。
2. 浮窗可切换「层级 / 全景」模式与「未扫描文件夹: 保持收起 / 自动扫描」策略；设置跨重启保留。
3. 全景模式初始状态与层级模式根层一致: 根目录的直接子项可见，文件夹全部收起。
4. 全景模式单击文件夹 = 原地展开 / 收起；展开时子项从文件夹位置散出，收起时子项缩回文件夹。
5. 展开后的文件夹与其子项形成以文件夹为中心的「岛」（cluster）: 子项围绕父文件夹浮动，以极淡的细线（包含线）连到父文件夹。
6. 引用线一端位于收起的文件夹内时，连到该文件夹；展开后自动改连到更深一层的真实端点。
7. 单击带引用线的收起文件夹，沿引用端点所在路径连续展开，直到真实相关的子文件显露；与引用无关的子文件夹保持收起。
8. 全景模式工具区提供「全部展开」「全部收起」两个按钮。
9. 外观与手感延续层级模式（对标 Obsidian Graph View）；全景模式在本项目全部展开时拖拽、缩放无明显卡顿。
10. `npm run typecheck` → `lint` → `test` → `build` → `test:journey` 全绿。

## 3. 视图设置浮窗

| 设置项       | 选项                | 默认     | 生效范围                                                                 |
| ------------ | ------------------- | -------- | ------------------------------------------------------------------------ |
| 视图模式     | 层级 / 全景         | 层级     | 切换时画布重置到根目录初始状态                                           |
| 未扫描文件夹 | 保持收起 / 自动扫描 | 保持收起 | 全景「全部展开」与连续展开；手动单击未扫描文件夹始终扫描（与文件树一致） |
| 显示包含线   | 开 / 关             | 开       | 仅全景；关闭后岛仍由布局力维持，只是不画线                               |

- 按钮位于工具区最右，与「适应画布」并列；浮窗贴按钮下方右对齐，层级取 `--z-popover`。
- 收起逻辑复用 `useMenuDismiss`；设置读写复用 `shared/localPrefs` 的 `readPref / writePref`（属用户偏好，非缓存，符合「不写入无意义缓存」契约）。
- 新增图标 `moreVertical`（lucide ellipsis-vertical 线稿）登记进 `Icons.tsx`。
- 浮窗为配置驱动: 设置项清单集中定义于 `graph/graphSettings.ts`，新增设置只追加清单项，不改浮窗组件。

## 4. 全景模式规则

### 4.1 可见性

- 状态: 已展开文件夹集合 `expanded: Set<relPath>`；根目录恒为展开。
- 节点可见 ⇔ 其全部祖先文件夹都在 `expanded` 中。
- 根目录本身不画节点（与层级模式一致），根的直接子项自由漂浮。

### 4.2 边

| 边                    | 规则                                                                                     | 视觉                                      |
| --------------------- | ---------------------------------------------------------------------------------------- | ----------------------------------------- |
| 包含线（containment） | 可见节点 → 其父文件夹（父为根时不画）                                                    | 极淡细线，无箭头                          |
| 引用线                | 每条原始引用的两端各映射到「最近的可见祖先或自身」；映射后两端相同丢弃；同端点对合并计数 | 同层级模式: 细灰线 + 箭头，线宽随条数增加 |

**映射规则（nearest visible ancestor）**: 文件 `a/b/c.ts`，若 `a` 收起 → 映射为 `a`；若 `a` 展开、`a/b` 收起 → 映射为 `a/b`；全部展开 → 文件自身。

### 4.3 连续展开（reveal）

单击收起文件夹 `F`:

1. 收集所有「一端在 `F` 内、另一端在 `F` 外」的原始引用，取其位于 `F` 内的端点文件。
2. 若集合为空 → 只展开 `F` 一层。
3. 否则展开 `F` 及这些端点文件的全部祖先文件夹（位于 `F` 之下的部分）；路径上遇到未扫描文件夹时按「未扫描文件夹」设置处理。

单击已展开文件夹 → 收起它及其全部后代文件夹。

### 4.4 全部展开 / 全部收起

- 全部展开: 按广度优先展开全部已扫描文件夹；设置为「自动扫描」时依次扫描未扫描文件夹（串行，复用 `handleExpandLazy`），工具区显示「正在读取文件夹 n/N」，「全部收起」可中止。
- 可见节点上限 `GRAPH_PANORAMA_MAX_NODES = 2000`: 全部展开到达上限即停止深入，提示「节点过多，已停在第 X 层；可单击文件夹继续展开」。
- 全部收起: `expanded` 清空为初始状态。

### 4.5 布局（岛状聚类）

| 力         | 全景取值（初值，集中在 `graphConfig`） | 作用                         |
| ---------- | -------------------------------------- | ---------------------------- |
| 包含线弹簧 | 距离 = 父半径 + 子半径 + 24，强度 0.8  | 子项紧贴父文件夹，形成岛     |
| 引用线弹簧 | 距离 90，强度 0.12                     | 保持联系但不撕裂岛           |
| 斥力       | -120，作用上限 400                     | 岛内子项互相散开、岛与岛分开 |
| 向心力     | 0.02                                   | 孤立项不飘远                 |

- 展开: 子项出生于父文件夹坐标 ± 小随机偏移，由斥力散开。
- 收起: 子项在 150ms 内插值移回父文件夹坐标并淡出，再从模拟中移除。
- 展开 / 收起只对模拟做温和加热（alpha 0.3），已有节点不重新布局。

### 4.6 交互差异

| 操作               | 层级模式     | 全景模式                                    |
| ------------------ | ------------ | ------------------------------------------- |
| 单击文件夹         | 进入该层     | 原地展开（4.3）/ 收起                       |
| 单击文件           | 打开文件预览 | 同左                                        |
| 面包屑 / Backspace | 返回上一层   | 不显示 / 无效                               |
| 外部节点           | 有           | 无（全部节点在同一画布）                    |
| 悬停高亮           | 引用邻居     | 引用邻居 + 父文件夹（包含线以较低亮度高亮） |

## 5. 性能

- spike 实测（node, d3-force, 随机连边）: 1000 节点 ≈ 5ms/tick，2000 节点 ≈ 11ms/tick，4000 节点 ≈ 24ms/tick。上限定 **2000 可见节点**（`GRAPH_PANO.maxNodes`）：布局加热期不掉得太难看，冷却后模拟即停。
- 命中检测保持线性遍历（2000 节点 × pointermove 开销可忽略），未引入 quadtree。
- 视锥裁剪已实现：视口外的节点、边、标签跳过绘制（drawGraph `worldBounds`）。
- 标签随缩放淡出时整段跳过文字绘制。
- 斥力近似参数 `theta` 保持 d3 默认 0.9。

## 6. 模块划分（实际落地）

| 文件                                                   | 职责                                                                                                                                                                        |
| ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/shared/graphPanorama.ts`                          | 纯函数: `buildPanoramaGraph`（可见节点 + 包含线 + 归并引用线）、`revealFolders`（连续展开路径 + blocked 未扫描目录）、`collectExpandedAll`（BFS + 上限截断）、`collapseSet` |
| `src/shared/graphView.ts`                              | `findDirNode / collectFilePaths / aggregate / computeDegrees` 导出共用；`LevelNode` 增 `expanded` 字段（全景文件夹标记）                                                    |
| `src/renderer/src/graph/graphSettings.ts`              | `GRAPH_SETTINGS` 配置清单、`readGraphPrefs / useGraphPrefs`（localStorage 键 `atlas.graphView`）                                                                            |
| `src/renderer/src/graph/useGraphExpand.ts`             | 全景展开状态机: `idle / busy / failed`；toggle（连续展开）、expandAll（串行扫描 + 上限）、collapseAll；本地树账本 spliceSubtree 即扫即算                                    |
| `src/renderer/src/graph/useGraphStage.ts`              | 两步装配: `useStageCore`（canvas + 渲染循环）→ `useGraphStage`（布局 + 视口）；中间插 nav 需要 render 先存在                                                                |
| `src/renderer/src/graph/useForceLayout.ts`             | `SceneInput`（key + nodes + edges）；全景力配置（包含线弹簧、弱引用线）；新节点从父坐标出生；移除节点记 `scene.dying`（缩回父级 + 淡出）                                    |
| `src/renderer/src/graph/drawGraph.ts`                  | 包含线（无箭头、恒细、低透明）、dying 插值绘制、视锥裁剪                                                                                                                    |
| `src/renderer/src/graph/useGraphRender.ts`             | dying 存在期间持续要帧                                                                                                                                                      |
| `src/renderer/src/components/GraphSettingsPopover.tsx` | 「更多选项」按钮 + 浮窗（`useMenuDismiss` 收起）                                                                                                                            |
| `src/renderer/src/components/GraphView.tsx`            | `GraphModeSwitch` 按偏好分发 `LevelCanvas` / `PanoCanvas`（模式切换重挂载归零）                                                                                             |
| `src/renderer/src/components/Icons.tsx`                | 新增 `moreVertical`（lucide ellipsis-vertical）；散开/收回复用 `chevronsUpDown / chevronsDownUp`                                                                            |

交互状态沿用单一状态变量；展开进程状态为 `ExpandStatus` 联合类型，不叠加布尔值。

## 7. 自测（已落地）

- `scripts/selftest-graphpanorama.mts`（已登记 `test:graphpanorama`，串进 `npm test`）: 初始可见性、最近可见祖先映射、包含线、目录内自引用丢弃、归并计数、连续展开路径（无关子文件夹保持收起）、lazy 目录记 blocked、全部展开上限截断。
- `selftest-graphview` 保持全绿（共用函数抽出后层级行为不变）。
- journey: 「更多选项」→ 切「全景」→ 键盘展开 src（断言节点数增加）→ 全部展开 → 全部收起（断言回到基数）→ 偏好持久化断言（localStorage `atlas.graphView`）→ 切回层级；含 `graph-pano-src` / `graph-pano-all` 截图。

## 8. 不做的事（non-goals）

- 3D 图谱、在图上编辑关系、布局持久化（每次打开重新布局）。
- 按文件类型着色分组、搜索过滤（后续可作为浮窗新设置项追加）。
- 全景模式下的面包屑。

## 9. 风险

| 风险                                      | 应对                                                   |
| ----------------------------------------- | ------------------------------------------------------ |
| 全部展开后节点过多导致卡顿                | 2000 上限 + 视锥裁剪 + 标签淡出跳绘；第一步 spike 实测 |
| 引用线弹簧把岛撕散，看不出归属            | 引用线强度远低于包含线；参数集中在 `graphConfig` 可调  |
| 连续展开一次翻出过多文件夹                | 只展开引用端点所在路径；受 2000 上限约束               |
| `handleExpandLazy` 同一时刻只允许一个扫描 | 自动扫描串行执行，扫描中禁用重复触发                   |
