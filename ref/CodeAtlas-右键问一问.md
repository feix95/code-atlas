# 需求表：右键问一问（问问小探针）

> 状态：已拍板，待施工；排在《CodeAtlas-面板收起与桌宠托管》之后（依赖其中的单实例锁 + 托盘 + 桌宠）
> 来源：2026-09-18 灵感窗口讨论；待敲定项均按哥推荐拍板，小葵有最终验收权
> 机制已拍板：走解压软件 / WPS 那条路——资源管理器右键注册表项，不是塞进其他软件自己画的菜单

## 一、为什么做（定位）

现在想问小探针一个文件里的事，流程是：打开 CodeAtlas → 打开项目 → 找到文件 → 提问。
目标：**在资源管理器里右键任意文件 → "问问小探针" → 小探针弹对话气泡直接开聊**，体验和应用内自由聊天一模一样。少三步，就是轻量工具该有的便捷。

## 二、原理说明（给未来施工的 AI 看的背景）

- 解压软件、WPS 往系统右键塞菜单，原理是写注册表：`HKCU\Software\Classes\*\shell\<名字>\command`，用户级注册，**不需要管理员权限**。`%1` 是被右键的文件路径，`Icon` 值可以挂菜单图标。
- 文件夹同理，写在 `HKCU\Software\Classes\Directory\shell\` 下。
- 右键菜单本质是"敲运行中程序的门"：点击后以文件路径为参数拉起 CodeAtlas，**靠单实例锁把路径转交给已经在跑的实例**；程序没在跑就冷启动（同样走锁）。
- Windows 11 会把这类传统菜单收进"显示更多选项"（Shift+F10 直接可见）。第一版接受这个行为，**不做** Win11 新式菜单（那要 MSIX + 代码签名，成本不值当）。

## 三、需求明细

### 3.1 注册表开关（设置页）

- 设置页新增"右键菜单"开关，**默认开**。
- 开 = 写入两个注册表项；关 = 删除。切换即时生效，不用重启电脑、不用重启 CodeAtlas。
- 两个菜单项：
  1. 文件右键 → **"问问小探针"**（`*\shell`）
  2. 文件夹右键 → **"用 CodeAtlas 打开"**（`Directory\shell`）
- 菜单项挂 CodeAtlas 图标（指向安装目录内的 exe/ico）。
- **仅安装版（NSIS）提供此开关**；注册表里写的命令路径必须指向当前安装位置的 exe。
- 卸载清理：electron-builder 目前没挂 NSIS 自定义脚本，要补一个 include 脚本，卸载时把这两个键删干净。

### 3.2 转交链路

- 右键文件 → 新进程带路径启动 → 单实例锁发现已有实例 → `second-instance` 把路径转交 → 新进程退出。
- 已有实例收到路径 → **桌宠弹出对话气泡**，气泡里明确显示"已选文件：xxx"，用户直接提问。
- 气泡 = 自由聊天换皮：**换皮不换脑**，复用 FreeChatPanel 的后端（agent 翻文件模式），聊天体验与应用内完全一致。
- 冷启动路径（程序没在跑）：先启动到托盘 + 桌宠，直接弹气泡开聊，**不强制展开主窗**。

### 3.3 出界文件策略（已拍板）

agent 的读文件工具全部走 `joinRoot` 围栏（只许读当前项目根以内）。右键的文件不一定在当前项目里，策略：

- **文件在当前项目内**：直接读，正常问答。
- **文件在项目外**：不静默失败、不报技术术语。气泡里说人话："这个文件不在我打开的项目里"，并给一个 **"把它的文件夹设为工作目录"** 按钮；用户点了就切根重读，问答继续；不点也可以就文件本身继续聊（走单文件读取，不换根）。
- "单文件通行证"（每次只授权读这一个文件）是二期候选，第一版先按上面两条走。

### 3.4 文件夹右键

- "用 CodeAtlas 打开"：以被右键的文件夹为项目根打开主窗。
- 冷启动 / 热转交两条路都要通：程序没跑就带根启动；跑着就把已有实例的主窗切到这个根并唤到前台（切根前如当前有打开的项目，弹确认，别悄悄丢掉人家正在看的项目）。

## 四、验收标准（逐条打勾，全绿才算完）

- [ ] 新增 IPC 通道收发严格成对（`invoke` 配 `handle`、`send` 配 `on`），沿用 selftest 的通道对账做法，自测覆盖新通道

## 五、边界与不做的事

- **不做 Win11 新式右键菜单**（MSIX + 签名路线，成本不值当；传统菜单藏在"显示更多选项"里可接受）。
- **不做多选文件一起问**（`%1` 一次传一个；多选以后真有需求再说）。
- **不做 portable 免安装版的右键开关**（没有卸载器，没人负责清理注册表，违反"不留垃圾"定位）。
- 注册表只写 `HKCU`（当前用户），**绝不写 `HKLM`**（那要管理员权限，还动别人机器的全局）。
