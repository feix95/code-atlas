# 需求表：面板收起 → 桌宠托管模式

> 状态：已拍板，待施工
> 来源：2026-09-18 灵感窗口讨论；待敲定项均按哥推荐拍板，小葵有最终验收权
> 施工顺序：本表为第一锤 + 第二锤（地基先行，桌宠后上）

## 一、为什么做（定位）

CodeAtlas 的定位是**轻量本地小工具**：绝对不生产多余垃圾、便捷、免费、视觉好看、足够小白。
现状是整个主窗常驻屏幕，"还是太重了"——只想随手聊两句的时候，不想摆出整个工程。

目标：**应用可以收起**，屏幕上只剩一只动画小桌宠；聊天不中断，随叫随到，不用了就当它不存在。

## 二、现状与硬前提（施工前必读）

- `src/main/index.ts` 目前**没有单实例锁**：程序跑着再双击一次会开出第二个实例。本项目当年就吃过双实例 GPU 缓存大战的亏（见主窗创建处的注释），桌宠和右键问一问都要求先补上。
- 现在的关窗语义是 `window-all-closed` → 直接 `app.quit()`：**一收起就整个程序死掉**，聊天和内置引擎全没了。必须先立托盘常驻，改掉这个语义。
- 透明无边框窗的路已经铺好：主窗和 Developer 日志窗都是 `frame:false + transparent:true + backgroundColor:'#00000000'`，桌宠窗照方抓药开第三个即可，别重新发明。
- 内置引擎（llama-server 子进程）在 `will-quit` 时停。改退出语义后，**托盘退出也必须走同一条清理链**，不能绕过。

## 三、需求明细

### 3.1 单实例锁（地基，A/B 共用）

- `app.requestSingleInstanceLock()`：抢不到锁的实例不建任何窗口，把启动参数转交给已有实例后自己退出。
- 已有实例通过 `second-instance` 事件接收转交的参数（文件路径，见右键问一问需求表）和唤起请求，把主窗带焦点唤回。

### 3.2 托盘常驻（地基）

- 启动后托盘有 CodeAtlas 图标，鼠标悬停有名字。
- 托盘右键菜单至少三项：**显示主面板 / 显示·隐藏桌宠 / 退出**。
- **关闭主窗 = 收到托盘**（隐藏 + 程序继续跑），不再触发退出；**真退出只走托盘菜单的"退出"**。
- "退出"走 `app.quit()`，让 `will-quit` 里的引擎清理链照常执行。

### 3.3 收起模式

- 收起 = 主窗整体隐藏：任务栏不留图标、Alt+Tab 里没有主窗。
- 收起不杀状态：聊天历史、会话上下文、正在生成的回答，唤回后原样都在。

### 3.4 桌宠窗

- 独立透明无边框窗口：置顶、`skipTaskbar`（不占任务栏）、默认出现在屏幕角落。
- **可拖动**，位置记住，重启回到上回待的地方。
- **可隐藏 / 可找回**：托盘菜单切换；隐藏后桌面干干净净，不留任何入口外的痕迹。
- **鼠标穿透**：桌宠图案以外的空白区域，鼠标点击穿透到桌面——不能让一块隐形玻璃挡着桌面用不了。
- **点击桌宠 = 唤回主面板**（带焦点）；桌宠本体被点击时有反应动画。
- **动画状态至少三个**：待机（空闲呼吸）、思考中（AI 生成期间）、说话（回答送达）。素材由小葵绘制（序列帧 PNG 或 CSS 动画都行），状态与触发时机见下表：

| 状态 | 触发时机 |
|---|---|
| 待机 | 空闲 |
| 思考中 | AI 请求已发出、回答未到 |
| 说话 | 回答送达、气泡展示期间 |

## 四、验收标准（逐条打勾，全绿才算完）

- [ ] `npm run dev` 后托盘出现图标；关闭主窗后程序不退出、托盘仍在
- [ ] 托盘"退出"后进程干净退场：任务管理器无残留 node/electron，内置引擎子进程一并停掉
- [ ] 收起后：任务栏无 CodeAtlas 窗口、Alt+Tab 无主窗；唤回后聊天历史原样还在
- [ ] 桌宠默认出现在屏幕角落；拖到任意位置，重启后位置与上回一致
- [ ] 桌宠图案外空白处点击，点的是桌面（穿透生效）；点桌宠本体有反应
- [ ] 隐藏桌宠后，托盘菜单能把它找回来
- [ ] 三个动画状态都能被真实触发：空闲待机 → 提问后思考中 → 回答送达说话
- [ ] 程序运行中再启动一次（双击 exe 或再跑 dev）：不出现第二个实例，已有实例的主窗被唤到前台
- [ ] `typecheck` / `lint` / `test` / `build` 全绿
- [ ] 系统显示缩放 125% 复查：桌宠位置、点击热区与图案对得上，无明显错位

## 五、边界与不做的事

- **不做开机自启**（以后真要，也是设置页里的显式开关，默认关）。
- **不做桌宠皮肤/多套形象**，第一版一套动画。
- **不改聊天本身的任何逻辑**——桌宠只是壳，脑（agent 后端）一动不动。
- 纯视觉判断（好不好看、动画顺不顺滑）按数值推算不算数，以小葵实际观感验收为准。
